# HIG Spec

Unofficial Apple UI component geometry reference, organized as per-component specifications.

**Status:** Early research preview. Layout measurements from Apple UI Kit design files are sample values in design coordinates, not guaranteed UIKit/AppKit runtime dimensions. This project is not affiliated with Apple.

The documentation site is intended for GitHub Pages at https://hig-spec.github.io/.

Source measurements and redistribution rights require review before expanding or republishing original design assets. Do not distribute Apple UI Kit artwork, images or fonts as part of this project.
